    How to use this page

    1. Pick a question and use its GfG link (opens in a new tab).
    2. Links labelled Open GfG go to a guide page — use its “Try It Yourself” link to reach the practice editor. Links labelled Solve on GfG go straight to the practice problem.
    3. After solving it on GfG, set the status here. Use Revisit for problems you want to practise again.
    4. Optional: Sign in (Google, GitHub or email) to get a profile and keep your progress across devices.
    Open it locally & host it

    Open locally

    Save this file as index.html and double-click it. The tracker works without a server; sign-in needs the page served over http(s) (for local testing run npx serve in the folder and open http://localhost:3000). Progress is saved per browser (and per file location), so use Export/Import if you open it from a different place.

    Host as a static website

    • GitHub Pages: put index.html in a repository → Settings → Pages → deploy from your main branch.
    • Netlify / Cloudflare Pages / Vercel: drag the folder containing index.html into the dashboard, or connect a repo (no build command, publish directory is the root).
    • Any web host: upload index.html to the site's public folder.

    Each hosting address has its own saved progress; moving to a new address means using Export, then Import.

    About GfG sync

    GeeksforGeeks does not document a public, permitted API for reading a user's accepted submissions, so this page does not try to read your GfG account — no scraping, no private endpoints, no logins or cookies. Completion is marked manually. The code has a small integrations registry so an official integration can be added later if GfG offers one.
